# 标签体系

skill 自动打标签时，按本表归类。不要向用户索要标签。

## 业务域（一级类，可多选，最多 3 个）

| 业务域 | 覆盖 | 示例关键词 |
|---|---|---|
| 增长 | 拉新、获客、裂变、投放 | 拉新、获客成本、裂变、渠道、投放 |
| 留存 | 活跃、召回、流失 | 次日留存、召回、流失预警、活跃 |
| 转化 | 付费、成交、漏斗 | 转化率、成交、付费、漏斗、复购 |
| 效率 | 流程、工具、自动化 | 提效、流程优化、工具、自动化 |
| 质量 | 品控、缺陷、稳定性、性能 | 质量、缺陷、稳定性、性能、可用性 |
| 协作 | 沟通、对齐、跨部门 | 协作、对齐、沟通、跨团队、评审 |
| 成本 | 降本、资源优化 | 降本、成本、资源、ROI |
| 风险 | 合规、安全、异常 | 风险、合规、安全、异常、容灾 |

## 方法论类型（主类，单选）

| 类型 | 判据（回答什么问题） | 示例 |
|---|---|---|
| 决策原则 | 怎么选 / 怎么判断，是原则不是步骤 | 「需求优先级按影响 × 成本打分」 |
| 操作SOP | 按什么步骤做，可逐步执行 | 「活动复盘五步法」 |
| 判断标准 | 到什么程度算好 / 该停，含量化阈值 | 「A/B 实验显著性阈值」 |
| 模板清单 | 可直接套用的模板 / Checklist | 「PRD 自检清单」 |
| 教训反例 | 别做什么，来自失败或反例 | 「xx 场景不要提前承诺排期」 |

## 角色

运营 / 产品 / 开发（由输入决定，已在卡片 frontmatter 标注，不重复计入标签）。

## 打标签规则

1. 业务域选最贴切的一级类，可多选（最多 3 个）。
2. 方法论类型只选一个主类。
3. 不要新增不在表内的类别；确有需要时在卡片里注明「新类别建议」，并沿用最接近的现有类。
